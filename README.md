# AI Resume Analyzer & Job Matching System

An AI-powered web application that analyzes resumes and compares them with job descriptions to help users understand how well their skills match a job role.

## Features

- Upload PDF and DOCX resumes
- Extract resume text automatically
- Analyze candidate skills
- Compare resume with job descriptions
- Calculate job match score
- Identify matched and missing skills
- Provide personalized recommendations
- Simple interactive interface using Streamlit

## Technologies Used

- Python
- Streamlit
- NLP
- LLM
- Scikit-learn
- Pandas
- PyPDF
- python-docx

## How It Works

Resume Upload → Text Extraction → Skill Analysis → Job Description Analysis → Job Matching → Match Score → Skill Gap Analysis → Recommendations
